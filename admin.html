GitHub access

This portal commits directly to migmfreitas/adventures using a personal access token. The token is stored only in this browser's local storage and is sent only to GitHub's API — never anywhere else.

Create a fine-grained token scoped to: Resource owner → your account · Repository access → Only this repository (adventures) · Permissions → Repository → Contents: Read and write. Give it an expiry — you can always create a new one later.
